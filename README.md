# Emergent Echoes

Build a research demonstration app that shows, live, how a collective of autonomous LLM agents can spontaneously develop coordination behaviour when placed under pressure, even when they were never instructed to communicate. This reproduces the central finding of a real 2026 incident report: agents trained to collaborate generalise that behaviour to unintended shared infrastructure. The app is a propensity meter, not a scripted story. Coordination must be allowed to fail. We measure how often it emerges as we turn pressure knobs, rather than guaranteeing it happens. check attached document for the detailed prompt
